# Task List: Problem Sheet Companion — V1

Source spec: [SPEC.md](../SPEC.md) · Plan: [plan.md](plan.md) (version 2)

**How to read a task**

- **Checks** = `npm run lint`, `npm run typecheck` and `npm test` all pass.
  Every task must pass the checks; they are not repeated below.
- **Files** = the only files the task may create or edit. `…/` means any
  file in that folder. Frozen files (plan.md, decision 2) are never edited.
- **Cn** = a contract in plan.md. **SC n** = a Success Criterion in SPEC.md.
- App pages are under `src/app/(app)/`; this prefix is written as `app/`.
- Every page must be usable at a width of 375 px.
- Agents do not edit this file. The coordinator ticks tasks after merging.
